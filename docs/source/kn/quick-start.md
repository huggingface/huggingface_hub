# ಕ್ವಿಕ್‌ಸ್ಟಾರ್ಟ್

ಮಷಿನ್ ಲರ್ನಿಂಗ್ ಮಾಡೆಲ್‌ಗಳು, ಡೆಮೊಗಳು, ಡೇಟಾಸೆಟ್‌ಗಳು ಮತ್ತು ಮೆಟ್ರಿಕ್‌ಗಳನ್ನು ಹಂಚಿಕೊಳ್ಳಲು
[Hugging Face Hub](https://huggingface.co/) ಅತ್ಯುತ್ತಮ ತಾಣ. ನಿಮ್ಮ ಡೆವಲಪ್‌ಮೆಂಟ್ ಪರಿಸರದಿಂದ
ಹೊರಬರದೆಯೇ ಹಬ್ ಜೊತೆ ಸಂವಹನ ನಡೆಸಲು `huggingface_hub` ಲೈಬ್ರರಿ ನೆರವಾಗುತ್ತದೆ. ರಿಪೊಸಿಟರಿಗಳನ್ನು
ಸುಲಭವಾಗಿ ರಚಿಸಿ ನಿರ್ವಹಿಸಬಹುದು, ಫೈಲ್‌ಗಳನ್ನು ಡೌನ್‌ಲೋಡ್ ಮತ್ತು ಅಪ್‌ಲೋಡ್ ಮಾಡಬಹುದು, ಮತ್ತು ಹಬ್‌ನಿಂದ
ಮಾಡೆಲ್ ಹಾಗೂ ಡೇಟಾಸೆಟ್ ಬಗೆಗಿನ ಉಪಯುಕ್ತ ಮೆಟಾಡೇಟಾವನ್ನು ಪಡೆಯಬಹುದು.

## ಇನ್‌ಸ್ಟಾಲೇಶನ್

ಆರಂಭಿಸಲು, `huggingface_hub` ಲೈಬ್ರರಿಯನ್ನು ಇನ್‌ಸ್ಟಾಲ್ ಮಾಡಿ:

```bash
pip install --upgrade huggingface_hub
```

ಹೆಚ್ಚಿನ ವಿವರಗಳಿಗಾಗಿ [ಇನ್‌ಸ್ಟಾಲೇಶನ್](installation) ಮಾರ್ಗದರ್ಶಿ ನೋಡಿ.

> [!TIP]
> `huggingface_hub` ಜೊತೆಗೆ [`hf` CLI](./guides/cli) ಕೂಡ ಬರುತ್ತದೆ. ಇದರಿಂದ ಟರ್ಮಿನಲ್‌ನಿಂದ ನೇರವಾಗಿ ಹಬ್ ಜೊತೆ ಸಂವಹನ ನಡೆಸಬಹುದು.
> ನೀವು AI ಏಜೆಂಟ್‌ಗಳನ್ನು (Claude Code, Codex, Cursor, ...) ಬಳಸುತ್ತಿದ್ದರೆ, ನಿಮ್ಮ ಏಜೆಂಟ್ CLI ಅನ್ನು ಬಳಸುವಂತೆ ಮಾಡಲು Skill ಅನ್ನು ಇನ್‌ಸ್ಟಾಲ್ ಮಾಡಿ:
> ```bash
> # for Codex, Cursor, OpenCode, Pi and other agents that load skills from `.agents/skills`
> hf skills add
> # includes the above + Claude Code
> hf skills add --claude
> ```
> ಹೆಚ್ಚಿನ ವಿವರಗಳಿಗಾಗಿ [Hugging Face CLI for AI Agents](https://huggingface.co/docs/hub/agents-cli) ಮಾರ್ಗದರ್ಶಿ ನೋಡಿ.

## ಫೈಲ್‌ಗಳನ್ನು ಡೌನ್‌ಲೋಡ್ ಮಾಡುವುದು

ಹಬ್‌ನಲ್ಲಿರುವ ರಿಪೊಸಿಟರಿಗಳು git ಆವೃತ್ತಿ ನಿಯಂತ್ರಣದಲ್ಲಿರುತ್ತವೆ, ಮತ್ತು ಬಳಕೆದಾರರು ಒಂದೇ ಫೈಲ್ ಅನ್ನಾಗಲೀ
ಇಡೀ ರಿಪೊಸಿಟರಿಯನ್ನಾಗಲೀ ಡೌನ್‌ಲೋಡ್ ಮಾಡಬಹುದು. ಫೈಲ್‌ಗಳನ್ನು ಡೌನ್‌ಲೋಡ್ ಮಾಡಲು [`hf_hub_download`] ಫಂಕ್ಷನ್
ಬಳಸಬಹುದು. ಈ ಫಂಕ್ಷನ್ ಫೈಲ್ ಅನ್ನು ಡೌನ್‌ಲೋಡ್ ಮಾಡಿ ನಿಮ್ಮ ಸ್ಥಳೀಯ ಡಿಸ್ಕ್‌ನಲ್ಲಿ ಕ್ಯಾಶ್ ಮಾಡುತ್ತದೆ. ಮುಂದಿನ ಬಾರಿ
ಆ ಫೈಲ್ ಬೇಕಾದಾಗ ಅದು ಕ್ಯಾಶ್‌ನಿಂದಲೇ ಲೋಡ್ ಆಗುತ್ತದೆ, ಹಾಗಾಗಿ ಮತ್ತೆ ಡೌನ್‌ಲೋಡ್ ಮಾಡಬೇಕಾಗಿಲ್ಲ.

ನಿಮಗೆ ಬೇಕಾದ ಫೈಲ್‌ನ ರಿಪೊಸಿಟರಿ ಐಡಿ ಮತ್ತು ಫೈಲ್‌ಹೆಸರು ಬೇಕಾಗುತ್ತದೆ. ಉದಾಹರಣೆಗೆ,
[Pegasus](https://huggingface.co/google/pegasus-xsum) ಮಾಡೆಲ್‌ನ ಕಾನ್ಫಿಗರೇಶನ್ ಫೈಲ್ ಅನ್ನು
ಡೌನ್‌ಲೋಡ್ ಮಾಡಲು:

```py
>>> from huggingface_hub import hf_hub_download
>>> hf_hub_download(repo_id="google/pegasus-xsum", filename="config.json")
```

ಫೈಲ್‌ನ ನಿರ್ದಿಷ್ಟ ಆವೃತ್ತಿಯನ್ನು ಡೌನ್‌ಲೋಡ್ ಮಾಡಲು, ಬ್ರಾಂಚ್ ಹೆಸರು, ಟ್ಯಾಗ್ ಅಥವಾ ಕಮಿಟ್ ಹ್ಯಾಶ್ ಅನ್ನು ಸೂಚಿಸಲು
`revision` ಪ್ಯಾರಾಮೀಟರ್ ಬಳಸಿ. ಕಮಿಟ್ ಹ್ಯಾಶ್ ಬಳಸಿದರೆ ಅದು ಚಿಕ್ಕ 7-ಅಕ್ಷರದ ಹ್ಯಾಶ್ ಅಲ್ಲದೆ ಪೂರ್ಣ ಉದ್ದದ
ಹ್ಯಾಶ್ ಆಗಿರಬೇಕು:

```py
>>> from huggingface_hub import hf_hub_download
>>> hf_hub_download(
...     repo_id="google/pegasus-xsum",
...     filename="config.json",
...     revision="4d33b01d79672f27f001f6abade33f22d993b151"
... )
```

ಹೆಚ್ಚಿನ ವಿವರಗಳು ಮತ್ತು ಆಯ್ಕೆಗಳಿಗಾಗಿ [`hf_hub_download`] ನ API ರೆಫರೆನ್ಸ್ ನೋಡಿ.

## ದೃಢೀಕರಣ (Authentication)

ಹಬ್ ಜೊತೆ ಸಂವಹನ ನಡೆಸಲು ಹಲವು ಸಂದರ್ಭಗಳಲ್ಲಿ ನೀವು Hugging Face ಖಾತೆಯೊಂದಿಗೆ ದೃಢೀಕರಣಗೊಂಡಿರಬೇಕು:
ಖಾಸಗಿ ರಿಪೊಗಳನ್ನು ಡೌನ್‌ಲೋಡ್ ಮಾಡುವುದು, ಫೈಲ್‌ಗಳನ್ನು ಅಪ್‌ಲೋಡ್ ಮಾಡುವುದು, PR ರಚಿಸುವುದು,...
ಇನ್ನೂ ಖಾತೆ ಇಲ್ಲದಿದ್ದರೆ [ಖಾತೆ ತೆರೆಯಿರಿ](https://huggingface.co/join).

### ಲಾಗಿನ್ ಕಮಾಂಡ್

ದೃಢೀಕರಣಕ್ಕೆ ಅತ್ಯಂತ ಸುಲಭ ದಾರಿ [`login`] ಕಮಾಂಡ್:

```bash
hf auth login
```

ನೀವು ಈಗಾಗಲೇ ಲಾಗಿನ್ ಆಗಿದ್ದರೆ ಕಮಾಂಡ್ ತಕ್ಷಣ ಮರಳುತ್ತದೆ. ಒತ್ತಾಯಪೂರ್ವಕವಾಗಿ ಮತ್ತೆ ಲಾಗಿನ್ ಆಗಲು `hf auth login --force` ಬಳಸಿ. ಲಾಗಿನ್ ಆಗಿಲ್ಲದಿದ್ದರೆ, ಬ್ರೌಸರ್ ಮೂಲಕ ಲಾಗಿನ್ ಆಗುವಂತೆ ಕೇಳಲಾಗುತ್ತದೆ: ತೋರಿಸಿದ URL ತೆರೆಯಿರಿ, ಚಿಕ್ಕ ಕೋಡ್ ನಮೂದಿಸಿ, ಮನವಿಯನ್ನು ಅನುಮೋದಿಸಿ — ಆಗ ಒಂದು ಆ್ಯಕ್ಸೆಸ್ ಟೋಕನ್ ಪಡೆದು ನಿಮ್ಮ `HF_HOME` ಡೈರೆಕ್ಟರಿಯಲ್ಲಿ (ಪೂರ್ವನಿಯೋಜಿತವಾಗಿ `~/.cache/huggingface/token`) ಉಳಿಸಲಾಗುತ್ತದೆ. ಸ್ವಲ್ಪ ಸಮಯದ ನಂತರ ಟೋಕನ್ ಅವಧಿ ಮುಗಿಯುತ್ತದೆ, ಆದರೆ ನೀವು ಅದನ್ನು ಬಳಸುತ್ತಿರುವವರೆಗೆ ಅದು ತಾನಾಗಿಯೇ ನವೀಕರಣಗೊಳ್ಳುತ್ತದೆ. ಹಬ್ ಜೊತೆ ಸಂವಹನ ನಡೆಸುವ ಯಾವುದೇ ಸ್ಕ್ರಿಪ್ಟ್ ಅಥವಾ ಲೈಬ್ರರಿ ರಿಕ್ವೆಸ್ಟ್ ಕಳುಹಿಸುವಾಗ ಈ ಟೋಕನ್ ಬಳಸುತ್ತದೆ. ಪರ್ಯಾಯವಾಗಿ, ನಿಮ್ಮ [ಸೆಟ್ಟಿಂಗ್ಸ್ ಪುಟದಿಂದ](https://huggingface.co/settings/tokens) ರಚಿಸಿದ [ಬಳಕೆದಾರ ಆ್ಯಕ್ಸೆಸ್ ಟೋಕನ್](https://huggingface.co/docs/hub/security-tokens) ಅನ್ನು ಅಂಟಿಸಬಹುದು.

> [!TIP]
> ಬಳಕೆದಾರ ಆ್ಯಕ್ಸೆಸ್ ಟೋಕನ್‌ಗಳಿಗೆ `read` ಅಥವಾ `write` ಅನುಮತಿ ಇರಬಹುದು. ರಿಪೊಸಿಟರಿಯನ್ನು ರಚಿಸಲು ಅಥವಾ ಸಂಪಾದಿಸಲು ಬಯಸಿದರೆ `write` ಆ್ಯಕ್ಸೆಸ್ ಟೋಕನ್ ಇರುವಂತೆ ನೋಡಿಕೊಳ್ಳಿ. ಇಲ್ಲವಾದರೆ, ಟೋಕನ್ ಆಕಸ್ಮಿಕವಾಗಿ ಸೋರಿಕೆಯಾದರೆ ಅಪಾಯ ಕಡಿಮೆ ಇರುವಂತೆ `read` ಟೋಕನ್ ರಚಿಸುವುದೇ ಉತ್ತಮ.

ಪರ್ಯಾಯವಾಗಿ, ನೋಟ್‌ಬುಕ್ ಅಥವಾ ಸ್ಕ್ರಿಪ್ಟ್‌ನಲ್ಲಿ [`login`] ಬಳಸಿ ಪ್ರೋಗ್ರಾಂ ಮೂಲಕವೂ ಲಾಗಿನ್ ಆಗಬಹುದು:

```py
>>> from huggingface_hub import login
>>> login()
```

ಒಂದು ಸಮಯದಲ್ಲಿ ಒಂದೇ ಖಾತೆಗೆ ಮಾತ್ರ ಲಾಗಿನ್ ಆಗಿರಲು ಸಾಧ್ಯ. ಹೊಸ ಖಾತೆಗೆ ಲಾಗಿನ್ ಆದರೆ ಹಿಂದಿನ ಖಾತೆಯಿಂದ ತಾನಾಗಿಯೇ ಲಾಗ್‌ಔಟ್ ಆಗುತ್ತೀರಿ. ಸದ್ಯ ಯಾವ ಖಾತೆ ಸಕ್ರಿಯವಾಗಿದೆ ಎಂದು ತಿಳಿಯಲು `hf auth whoami` ಕಮಾಂಡ್ ಚಲಾಯಿಸಿ.

> [!WARNING]
> ಒಮ್ಮೆ ಲಾಗಿನ್ ಆದ ಮೇಲೆ, ಹಬ್‌ಗೆ ಹೋಗುವ ಎಲ್ಲ ರಿಕ್ವೆಸ್ಟ್‌ಗಳೂ — ದೃಢೀಕರಣ ಅಗತ್ಯವಿಲ್ಲದ ಮೆಥಡ್‌ಗಳೂ ಸೇರಿ — ಪೂರ್ವನಿಯೋಜಿತವಾಗಿ ನಿಮ್ಮ ಆ್ಯಕ್ಸೆಸ್ ಟೋಕನ್ ಬಳಸುತ್ತವೆ. ಟೋಕನ್‌ನ ಈ ಸೂಚ್ಯ ಬಳಕೆಯನ್ನು ನಿಷ್ಕ್ರಿಯಗೊಳಿಸಲು `HF_HUB_DISABLE_IMPLICIT_TOKEN=1` ಎಂಬ ಎನ್ವಿರಾನ್‌ಮೆಂಟ್ ವೇರಿಯಬಲ್ ಹೊಂದಿಸಿ ([ರೆಫರೆನ್ಸ್](../package_reference/environment_variables#hfhubdisableimplicittoken) ನೋಡಿ).

### ಸ್ಥಳೀಯವಾಗಿ ಹಲವು ಟೋಕನ್‌ಗಳ ನಿರ್ವಹಣೆ

ಪ್ರತಿ ಟೋಕನ್‌ನೊಂದಿಗೆ [`login`] ಕಮಾಂಡ್ ಬಳಸಿ ಲಾಗಿನ್ ಆಗುವ ಮೂಲಕ ನಿಮ್ಮ ಮೆಷಿನ್‌ನಲ್ಲಿ ಹಲವು ಟೋಕನ್‌ಗಳನ್ನು ಉಳಿಸಬಹುದು. ಈ ಟೋಕನ್‌ಗಳ ನಡುವೆ ಸ್ಥಳೀಯವಾಗಿ ಬದಲಾಯಿಸಬೇಕಾದರೆ [`auth switch`] ಕಮಾಂಡ್ ಬಳಸಿ:

```bash
hf auth switch
```

ಉಳಿಸಿದ ಟೋಕನ್‌ಗಳ ಪಟ್ಟಿಯಿಂದ ಹೆಸರಿನ ಮೂಲಕ ಒಂದು ಟೋಕನ್ ಆಯ್ಕೆ ಮಾಡುವಂತೆ ಈ ಕಮಾಂಡ್ ಕೇಳುತ್ತದೆ. ಆಯ್ಕೆ ಮಾಡಿದ ಮೇಲೆ ಆ ಟೋಕನ್ _ಸಕ್ರಿಯ_ ಟೋಕನ್ ಆಗುತ್ತದೆ ಮತ್ತು ಹಬ್ ಜೊತೆಗಿನ ಎಲ್ಲ ಸಂವಹನಗಳಿಗೂ ಅದನ್ನೇ ಬಳಸಲಾಗುತ್ತದೆ.


ನಿಮ್ಮ ಮೆಷಿನ್‌ನಲ್ಲಿ ಲಭ್ಯವಿರುವ ಎಲ್ಲ ಆ್ಯಕ್ಸೆಸ್ ಟೋಕನ್‌ಗಳನ್ನು `hf auth list` ಮೂಲಕ ನೋಡಬಹುದು.

### ಎನ್ವಿರಾನ್‌ಮೆಂಟ್ ವೇರಿಯಬಲ್

ದೃಢೀಕರಣಕ್ಕೆ `HF_TOKEN` ಎಂಬ ಎನ್ವಿರಾನ್‌ಮೆಂಟ್ ವೇರಿಯಬಲ್ ಅನ್ನೂ ಬಳಸಬಹುದು. Space ನಲ್ಲಿ ಇದು ವಿಶೇಷವಾಗಿ ಉಪಯುಕ್ತ — ಅಲ್ಲಿ `HF_TOKEN` ಅನ್ನು [Space ಸೀಕ್ರೆಟ್](https://huggingface.co/docs/hub/spaces-overview#managing-secrets) ಆಗಿ ಹೊಂದಿಸಬಹುದು.

> [!TIP]
> **ಹೊಸದು:** Google Colaboratory ನಿಮ್ಮ ನೋಟ್‌ಬುಕ್‌ಗಳಿಗೆ [ಖಾಸಗಿ ಕೀಗಳನ್ನು](https://twitter.com/GoogleColab/status/1719798406195867814) ವ್ಯಾಖ್ಯಾನಿಸಲು ಅವಕಾಶ ನೀಡುತ್ತದೆ. ತಾನಾಗಿಯೇ ದೃಢೀಕರಣಗೊಳ್ಳಲು `HF_TOKEN` ಸೀಕ್ರೆಟ್ ಅನ್ನು ವ್ಯಾಖ್ಯಾನಿಸಿ!

ಎನ್ವಿರಾನ್‌ಮೆಂಟ್ ವೇರಿಯಬಲ್ ಅಥವಾ ಸೀಕ್ರೆಟ್ ಮೂಲಕ ಆಗುವ ದೃಢೀಕರಣಕ್ಕೆ, ನಿಮ್ಮ ಮೆಷಿನ್‌ನಲ್ಲಿ ಉಳಿಸಿದ ಟೋಕನ್‌ಗಿಂತ ಹೆಚ್ಚಿನ ಆದ್ಯತೆ ಇರುತ್ತದೆ.

### ಮೆಥಡ್ ಪ್ಯಾರಾಮೀಟರ್‌ಗಳು

ಕೊನೆಯದಾಗಿ, `token` ಅನ್ನು ಪ್ಯಾರಾಮೀಟರ್ ಆಗಿ ಸ್ವೀಕರಿಸುವ ಯಾವುದೇ ಮೆಥಡ್‌ಗೆ ನಿಮ್ಮ ಟೋಕನ್ ಅನ್ನು ರವಾನಿಸಿಯೂ ದೃಢೀಕರಣ ಮಾಡಬಹುದು.

```
from huggingface_hub import whoami

user = whoami(token=...)
```

ಟೋಕನ್ ಅನ್ನು ಶಾಶ್ವತವಾಗಿ ಉಳಿಸಲು ಬಯಸದ ಪರಿಸರದಲ್ಲಿ ಅಥವಾ ಒಂದೇ ಬಾರಿಗೆ ಹಲವು ಟೋಕನ್‌ಗಳನ್ನು ನಿಭಾಯಿಸಬೇಕಾದಾಗ ಹೊರತುಪಡಿಸಿ, ಸಾಮಾನ್ಯವಾಗಿ ಈ ವಿಧಾನ ಶಿಫಾರಸು ಮಾಡುವುದಿಲ್ಲ.

> [!WARNING]
> ಟೋಕನ್‌ಗಳನ್ನು ಪ್ಯಾರಾಮೀಟರ್ ಆಗಿ ರವಾನಿಸುವಾಗ ಎಚ್ಚರವಾಗಿರಿ. ಕೋಡ್‌ಬೇಸ್ ಅಥವಾ ನೋಟ್‌ಬುಕ್‌ನಲ್ಲಿ ಟೋಕನ್ ಅನ್ನು ನೇರವಾಗಿ ಬರೆಯುವ ಬದಲು ಸುರಕ್ಷಿತ ವಾಲ್ಟ್‌ನಿಂದ ಲೋಡ್ ಮಾಡುವುದೇ ಯಾವಾಗಲೂ ಉತ್ತಮ ಅಭ್ಯಾಸ. ಆಕಸ್ಮಿಕವಾಗಿ ನಿಮ್ಮ ಕೋಡ್ ಹಂಚಿಕೊಂಡರೆ, ಹಾರ್ಡ್‌ಕೋಡ್ ಮಾಡಿದ ಟೋಕನ್‌ಗಳು ದೊಡ್ಡ ಸೋರಿಕೆ ಅಪಾಯವನ್ನು ತಂದೊಡ್ಡುತ್ತವೆ.

## ರಿಪೊಸಿಟರಿ ರಚಿಸುವುದು

ನೋಂದಣಿ ಮಾಡಿ ಲಾಗಿನ್ ಆದ ಮೇಲೆ, [`create_repo`] ಫಂಕ್ಷನ್ ಬಳಸಿ ರಿಪೊಸಿಟರಿ ರಚಿಸಿ:

```py
>>> from huggingface_hub import HfApi
>>> api = HfApi()
>>> api.create_repo(repo_id="super-cool-model")
```

ನಿಮ್ಮ ರಿಪೊಸಿಟರಿ ಖಾಸಗಿಯಾಗಿರಬೇಕೆಂದರೆ:

```py
>>> from huggingface_hub import HfApi
>>> api = HfApi()
>>> api.create_repo(repo_id="super-cool-model", private=True)
```

ಖಾಸಗಿ ರಿಪೊಸಿಟರಿಗಳು ನಿಮ್ಮನ್ನು ಹೊರತುಪಡಿಸಿ ಬೇರೆ ಯಾರಿಗೂ ಕಾಣಿಸುವುದಿಲ್ಲ.

> [!TIP]
> ರಿಪೊಸಿಟರಿ ರಚಿಸಲು ಅಥವಾ ಹಬ್‌ಗೆ ವಿಷಯವನ್ನು ಪುಶ್ ಮಾಡಲು, `write` ಅನುಮತಿ ಇರುವ ಬಳಕೆದಾರ ಆ್ಯಕ್ಸೆಸ್
> ಟೋಕನ್ ಒದಗಿಸಬೇಕು. ನಿಮ್ಮ [ಸೆಟ್ಟಿಂಗ್ಸ್ ಪುಟದಲ್ಲಿ](https://huggingface.co/settings/tokens) ಟೋಕನ್
> ರಚಿಸುವಾಗ ಅನುಮತಿಯನ್ನು ಆಯ್ಕೆ ಮಾಡಬಹುದು.

## ಫೈಲ್‌ಗಳನ್ನು ಅಪ್‌ಲೋಡ್ ಮಾಡುವುದು

ಹೊಸದಾಗಿ ರಚಿಸಿದ ರಿಪೊಸಿಟರಿಗೆ ಫೈಲ್ ಸೇರಿಸಲು [`upload_file`] ಫಂಕ್ಷನ್ ಬಳಸಿ. ನೀವು ಸೂಚಿಸಬೇಕಾದವು:

1. ಅಪ್‌ಲೋಡ್ ಮಾಡಬೇಕಾದ ಫೈಲ್‌ನ ಪಾತ್.
2. ರಿಪೊಸಿಟರಿಯಲ್ಲಿ ಫೈಲ್‌ನ ಪಾತ್.
3. ಫೈಲ್ ಸೇರಿಸಬೇಕಾದ ರಿಪೊಸಿಟರಿಯ ಐಡಿ.

```py
>>> from huggingface_hub import HfApi
>>> api = HfApi()
>>> api.upload_file(
...     path_or_fileobj="/home/lysandre/dummy-test/README.md",
...     path_in_repo="README.md",
...     repo_id="lysandre/test-model",
... )
```

ಒಂದೇ ಬಾರಿಗೆ ಒಂದಕ್ಕಿಂತ ಹೆಚ್ಚು ಫೈಲ್‌ಗಳನ್ನು ಅಪ್‌ಲೋಡ್ ಮಾಡಲು [ಅಪ್‌ಲೋಡ್](./guides/upload) ಮಾರ್ಗದರ್ಶಿ ನೋಡಿ —
ಫೈಲ್‌ಗಳನ್ನು ಅಪ್‌ಲೋಡ್ ಮಾಡುವ ಹಲವು ವಿಧಾನಗಳನ್ನು (git ಜೊತೆ ಅಥವಾ ಇಲ್ಲದೆ) ಅದು ಪರಿಚಯಿಸುತ್ತದೆ.

[ಹೇಗೆ-ಮಾಡುವುದು ಮಾರ್ಗದರ್ಶಿಗಳನ್ನು](./guides/overview) ಓದಲು ಶಿಫಾರಸು ಮಾಡುತ್ತೇವೆ:

- ಹಬ್‌ನಿಂದ ಫೈಲ್‌ಗಳನ್ನು [ಡೌನ್‌ಲೋಡ್ ಮಾಡಿ](./guides/download).
- ಹಬ್‌ಗೆ ಫೈಲ್‌ಗಳನ್ನು [ಅಪ್‌ಲೋಡ್ ಮಾಡಿ](./guides/upload).
